# MemorySearch 本机使用 SOP

照片自动核验版 · 视频原生搜索

适用：这台 Mac 上已经完成索引的现有图库。核对日期：2026-11-25。

> 日常只需打开现有入口、输入中文、查看原件。使用已有索引，无需重新建索引。

## 先找到正确文件夹

1. 打开 Finder，找到已安装的项目文件夹（以下记为 `<MEMORYSEARCH_PROJECT>`），进入 `local-supervised-index`。
2. 找不到时，在 Finder 搜索 `Open-Local-Memory.command`，确认其所在文件夹名是 `local-supervised-index`。可把这个文件夹加入 Finder 边栏，方便下次使用。
3. 后续步骤中的 Open、Stop、Status、Rollback 都指这个文件夹里的同名脚本。

## 第一次打开，或从旧实例切换

1. 如果已有旧查看窗口，先关闭它。
2. 双击 `Stop-Local-Memory.command`。再用 Status 确认状态为 `stopped` 或 `not_started`，然后继续。
3. 双击 `Open-Local-Memory.command`。它会先准备后台，再打开“本机照片与视频 · 离线查看器”。
4. 等界面出现查询框和媒体类型下拉框。首次模型准备会慢一些。

# 1　查找照片

## 输入一次，先看候选

1. 在媒体类型下拉框选择“照片”。
2. 在“用中文描述画面”输入框写你要找的内容，例如“帐篷”“汽车”或“白色汽车”。
3. 点击“查找”。先尝试一个明显物体，再尝试增加必要细节。
4. 搜索先显示原始候选；随后在本机核验这些照片。看到“正在本机核验照片”时，等待状态更新。

{{PHOTO_SEARCH}}

## 看清原图

每条照片结果下方有“查看原图”。点击后，会打开“本机原图”窗口；可以拉大窗口查看细节，关掉该原图窗口后继续搜索。

## 什么时候算这一页完成

原始候选出现，表示搜索已经返回；照片核验可能仍在继续。以“核验已完成”或明确的回退提示为准。不要把出现第一张卡片当作整页核验结束。

> 示例词只说明输入方法，不保证你的图库一定有对应内容。界面和图形示意均为合成，不是私人图库截图。

# 2　理解核验分组

核验完成后，原始前十会分成“核验支持”和“其他原始候选”。原始文件没有被删除，也不会为了凑数补入新文件。

{{PHOTO_GROUPS}}

## 先看支持区，再展开其余候选

“核验支持”里的照片获得了模型支持，但模型可能出错。仍应点“查看原图”，确认是否符合你的描述。

点击“展开其他原始候选 · N 个（未确认或未获支持）”，可查看其余候选。这里仍可能有正确答案；再次点击对应的“收起其他原始候选”按钮可收起。

## 随时恢复原始排序

点击“恢复原始排序”，查看完整原始结果。此时按钮变为“查看核验分组”；再点一次即可回到分组显示。

## 支持为 0 时

先展开其他候选，或恢复原始排序。支持为 0 表示本次没有获得明确支持，不等于图库中没有目标。

> 核验超时或不可用时，会显示“已回到原始排序；全部候选仍可查看”。保留原始候选就是正常回退，无需重建索引。

# 3　查找与播放视频

## 切换模式后，再点查找

1. 在媒体类型下拉框选择“视频内部画面”。
2. 输入可直接看见的物体或场景，例如“鸭子”“桥梁”“冰块”。
3. 点击“查找”。结果按原生相关性返回，最多十个原始视频。
4. 在目标条目点击“播放视频”。在播放器里播放、暂停或拖动进度条，查看视频内部画面。

{{VIDEO_SEARCH}}

## 如何查看命中内容

当前原生查看器从原视频开头播放。把鼠标移到播放器上，使用播放器的进度条拖动到不同时间，继续核对画面。

只要原视频某处确实包含你要找的画面，就可以是有效结果。当前查看器没有自动跳到“已确认命中时刻”的功能。

## 视频的当前边界

视频沿用原生搜索，没有照片那样的自动核验分组。相关性前十可能包含无关视频，也可能漏掉正确视频；不能把排序或分数当成准确率。

> 优先搜索物体或场景。动作方向、声音、身份与极短细节，尚未通过可靠性验收。

# 4　结束、更新与回滚

## 用完后怎样退出

1. 等当前查询或照片核验结束，关闭原图和查看器窗口。
2. 若希望停止后台并释放常驻模型，再双击 `Stop-Local-Memory.command`。
3. 双击 `Status-Local-Memory.command` 查看状态；`stopped` 或 `not_started` 表示没有正常运行的搜索服务。

关闭查看器窗口后，后台模型可能仍常驻。下次正常使用，双击 Open 即可。

## 安装新代码后如何加载

维护人员完成更新后，旧进程可能仍在使用旧代码。按“关闭旧窗口 → Stop → 等停止 → Open”的顺序重新打开。已有索引继续使用，无需重新导入或重建。

## 关闭照片自动核验，回到原始结果

1. 等当前查询结束，关闭查看器。
2. 在正式入口文件夹双击 `Rollback-Photo-Review.command`。
3. 为确保重新打开后状态清楚，再执行 Stop，然后 Open。

回滚只关闭照片自动核验；照片按原始结果显示，视频搜索和索引保持原样。它不会删除任何原件或索引。

> 回滚后，重复 Open 不会自动重新启用照片核验。需要恢复时，由维护人员重新启用已验证版本。

## 新增素材怎么办

当前原生界面没有已核实的增量导入按钮；Open 也不等于自动扫描新素材。本 SOP 面向现有索引。新增或移动素材前，应先由维护人员确认对应流程。

# 5　遇到问题，先这样处理

|看到的情况|优先处理|
|---|---|
|双击 Open 后没有出现窗口|确认打开的是 `local-supervised-index` 中的 Open。运行 Status 查看状态；如有旧实例，先 Stop，待停止后再 Open。|
|提示“服务尚未就绪”或“正在准备”|先等模型准备。仍不恢复时，保留 Status 或命令窗口里的错误提示，交给维护人员处理。|
|照片“核验支持”为空|展开其他原始候选，或点击“恢复原始排序”。不要直接把它理解为没有结果。|
|核验未完成、超时或不可用|查看自动回退保留的原始结果；可稍后重新查询。无需因此重建索引。|
|返回结果与描述不符|打开原图或播放视频确认。换成更清楚的单一物体描述，重新点击“查找”。|
|视频不播放或画面空白|先点该条目的“播放视频”。仍失败时，保留错误现象；确认原文件没有被移动，交由维护人员检查。|

## 看懂 Status 的几个词

`ready`：后台已准备好。`stopped` / `not_started`：服务未运行。`blocked`：启动被保护检查阻止，需要查看提示。

如果出现 `pilot` 或 `full_index`，先保留状态并确认是否仍有索引任务；不要为了打开界面反复停止或重启它。

## 少点几次，避免排队

先等这一条查询结束，再发下一条。切换照片/视频模式后，需要重新点击“查找”。

> 本机服务没有联网兜底。正常使用无需关闭整台 Mac 的网络，也无需手动下载模型或安装新的运行依赖。

# 6　日常速查与使用边界

## 一次完整使用

Finder 找到入口 → Open → 选照片或视频 → 输入中文并点“查找” → 看原图或播放 → 关闭窗口。切换旧实例时先 Stop；需要释放模型时也用 Stop。

## 记住这四点

- 搜索是相关性前十，不是全部相关文件的完整清单。
- 照片“核验支持”仍可能出错；其他候选仍可能正确。
- 视频结果没有经过照片式的二次核验，短场景和细节可能漏检。
- 原件或目录位置变化可能影响打开结果；本 SOP 不指导重建或搬迁索引。

## 入口速查

|脚本|用途|
|---|---|
|`Open-Local-Memory.command`|正常使用：启动后台并打开查看器。|
|`Stop-Local-Memory.command`|停止后台搜索，释放常驻模型。|
|`Status-Local-Memory.command`|只看后台状态和汇总计数。|

## 本文档核对范围

已核对当前启动脚本、原生查看器控件、照片分组与回退代码、视频播放逻辑及照片回滚脚本。以隔离的合成材料验证客户端，不打开私人图库，也不抓取私人窗口。

本文档不承诺私人图库的准确率，也没有把公开实验版、候选重排或未发布的视频核验写成正式功能。

> 最短记忆：Open 开始；照片可展开、可恢复；视频点播放再拖动；Stop 结束后台。现有索引不用重建。
