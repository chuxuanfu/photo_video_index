# 质量验证与限制

当前为实验版，通用识别准确度尚未建立，全库门禁保持关闭。软件检查通过，不表示描述、文字或语音已达到可接受的准确度。

## 分开衡量三类结果

- 程序正确性：只读原件、解码、相对路径、实际时间码、缓存和安全边界。
- 感知质量：断言是否符合画面、关键内容是否遗漏、文字和语音是否可靠。
- 处理覆盖：完整、部分、待复审、失败与不支持分别计数。省略有用内容不能计为成功识别。

## 防止少量案例过拟合

开发集用于改进，固定回归集用于检查旧问题。独立留出集不参与提示词、规则或阈值调整；按事件或近重复内容分组，避免相邻照片、同段视频跨集泄漏。只访问用户授权的根目录，实际查看仅限已选内容。

记录模型、配置、代码签名、输入与参考标准版本。看到留出集结果并据此调整后，该结果不能继续充当未见数据的证明。

## 必须分别报告

1. 错误事实：主体类别、关键属性、关系、文字数字等无依据的断言。
2. 核心内容召回：在输出前固定主要可见事实，统计保留多少；不能靠大量删减提高表面正确率。
3. 复核负担：部分完成、待复审和失败的比例，不能从分母中静默删除难例。
4. 覆盖与速度：支持格式、采样范围、耗时，以及 OCR、语音等组件未完成的范围。

说明样本量、选样偏差、参考标准不确定性和统计限制。小样本没有发现错误，不等于整个资料库不会出错；也不能承诺未知素材准确度永远单调提高。

## 缓存与新推理

复用相同像素和描述，可以验证哈希、路径、时间码、纯转换及约束兼容性。它不能计为模型从零识别成功；新推理必须另记实际调用和输出。

同一固定视觉检查点的多次读取，错误可能相关。“不提供先前候选”不等于两个独立模型；自称通过不是正确性证据。OCR 与语音另有本机核对流程，仍需统计遗漏。

## 放行原则

先固定指标及可接受阈值，再评测。保留错误与遗漏，不按结果事后改标准。旧集不能明显退步，独立留出集也需达标。证据不足就保留门禁，不用更多自评分、软件检查或缓存命中代替感知质量验证。

私人画面、标注、输出、清单和记录只放在忽略的本机目录。本文件仅说明通用验证协议，不含私人测试资料。
